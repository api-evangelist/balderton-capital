Data mesh, data governance, data fabric, data access management, lineage, observability, orchestration…. the ‘governance’ layer of the modern data stack has been attracting growing attention and debate (and confusing terminology). Whilst the concept of data governance is not new, the emergence of data mesh — a federated, decentralised approach to data governance, coined by Zhamak Dehghani in 2019 — is more recent.
